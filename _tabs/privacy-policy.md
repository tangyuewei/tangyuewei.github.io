本隐私政策说明 tangyuewei.com（以下称“本站”）在你访问或使用本站时，如何收集、使用、存储与保护你的信息。访问本站即表示你已知悉本政策的内容。

## 一、我们收集哪些信息

### 1. 你主动提供的信息

- 通过邮件联系本站时提供的邮箱地址与邮件正文内容。
- 使用评论区时，你需要通过 GitHub 账号授权登录，本站会显示你的 GitHub 公开昵称与头像；评论内容本身保存于 GitHub 的 Issues 系统，受 GitHub 隐私政策约束。

### 2. 自动收集的信息

你访问本站时，以下信息可能被自动记录：

- IP 地址
- 浏览器类型与版本、操作系统、设备类型
- 访问的页面、访问时间、来源页面
- Cookie 中存储的匿名标识符

## 二、Cookie 与同类技术

### 1. 第三方供应商与广告 Cookie

本站在部分页面展示 Google AdSense 广告。请特别注意：

> **第三方供应商（包括 Google）使用 Cookie 来根据用户先前访问本站或其他网站的记录投放广告。Google 使用广告 Cookie，使其及其合作伙伴能够根据用户访问本站和/或互联网上其他网站的情况向用户投放广告。**

Google 使用广告 Cookie 的完整说明详见：<https://policies.google.com/technologies/ads>

**如何退出个性化广告：**

- Google 广告设置：<https://www.google.com/settings/ads> 或 <https://adssettings.google.com>
- 第三方供应商个性化广告退出入口：<https://www.aboutads.info/choices/>、<https://www.youronlinechoices.com/>
- 你也可以在浏览器设置中禁用或删除 Cookie，但可能导致部分功能无法正常使用。

- 提供、维护与改进本站的内容与功能

## 四、信息的共享与披露

本站不会出售你的个人信息。仅在以下情形下共享：

- 上述第三方服务商，在其提供服务所必需的范围内处理
- 法律法规要求，或应司法机关、监管机构的合法要求
- 为保护本站、用户或公众的合法权益所必需

## 五、数据保留

- 统计类数据（访问量、IP、设备信息）按各服务商的默认周期保留，其中 Google Analytics 4 的用户数据保留期默认最长 14 个月，具体以该服务的默认设置为准。
- 邮件往来记录保留至咨询事项处理完毕后的一段合理期间。
- 评论内容保留于 GitHub Issues，直至你或本站管理者删除。

## 七、儿童隐私

本站内容面向成年技术人员，不面向儿童，也不会主动收集儿童的个人信息。依据《中华人民共和国个人信息保护法》，未满十四周岁的未成年人个人信息属于敏感个人信息，处理时须取得其父母或其他监护人的同意。若你是监护人并发现未成年人向本站提供了个人信息，请联系我们删除。
